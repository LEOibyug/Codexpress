统计口径与本地网关状态

成功率 = 成功 / 已结束请求；加权输出 TPS = 有效成功样本输出 token / 对应请求总耗时（秒），包含首 token 等待。TTFT 为首 token 延迟。缓存命中率仅使用明确报告缓存量、且输入未估算的样本；推理 token 属于输出 token，不额外累加。费用为已知部分 USD；上游账单与按价格估算的条数分别显示，缺失不代表免费。

诊断正文的保留限制

诊断只保留实际捕获的上游失败反馈，不是请求正文。单条错误正文捕获上限为 8 MiB，正文保留 30 天，总压缩正文上限为 128 MiB，超限时淘汰较早正文。分页读完仅代表读完可用数据；是否完整请看 body_complete、body_truncated、body_evicted 等诊断字段。历史记录中已经保存为“[已隐藏]”的值无法还原，面板不对现有正文增加替换。

这里只读取网关实际保留的数据。关闭捕获后，仍可阅读保留缓存；未捕获、已淘汰、缺失分片或旧快照缺少的信息会明确标记，不会重建不存在的请求正文。
