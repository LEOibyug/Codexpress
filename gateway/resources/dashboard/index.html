统计口径与本地网关状态

成功率 = 成功 / 已结束请求。输入输出比 = 输入 token 总量 / 输出 token 总量，显示为“输入 : 1”；输入包含缓存读取，不重复累加缓存，输出为零或计数不可用时显示“—”，含估算计数时标记“≈”。加权生成 TPS = 有效成功样本的输出 token 总量 / 对应计时之和（秒）。从首个输出 token 计到生成结束；旧记录缺少可靠生成计时时使用完整耗时。新记录缺少有效计时或确切输出 token 数时不计入。TTFT 为首 token 延迟。缓存命中率仅统计报告了缓存量且未估算输入的样本；推理 token 已计入输出。费用只显示已知的 USD 金额，缺失不代表免费。
