# 原来源接续与最终兜底验证

2026-10-20，build 8。用户明确确认cch与Clauder使用同一账号和API Key，并追加“删去加密块”的最终兜底及系统通知要求。

## 原因与行为

build7的连接别名已把旧对话带到本地网关，但旧请求自带网关从未见过的加密推理／压缩状态，严格绑定检查因此在访问上游前返回409。前一次legacy-provider-id检查仅验证旧ID的地址重定向，未覆盖先在网关外产生的opaque历史，这是验收缺口。

现在只为用户确认同账号／密钥且地址匹配的旧供应商建立受限本地凭据，绑定具体来源和身份摘要。首次旧状态可回到该原身份；源身份变化、已知硬状态互相冲突时不会直接把原密文发给其他源。未确认供应商保持原连接；切换CODEX_HOME清除确认。预览中的失效对应关系可清除，恢复和官方连接操作不受失效映射阻断。

最终兜底默认开启，可在路由关闭。原路由不可续接，或原源明确401/402/403/429拒绝，或返回已识别的invalid_encrypted_content／previous_response_not_found等状态错误时，尝试一次重建。只移除请求input中的加密推理／压缩条目和协议加密字段、旧previous/conversation/turn引用，保留可见消息、工具结果及无关metadata。没有修改本地历史。丢失隐藏推理或压缩摘要的风险明确展示，不宣称无损；已开始流、提交结果不明不重放，固定来源不跨源。

重建成功且来源身份仍当前时，保存所丢状态的SHA摘要与标记，后续仅排除旧状态，保留新来源返回的有效密文。已迁移来源不因原源恢复或网关重启被抢回，普通和受限本地凭据都支持此恢复路径。记录不包含正文、原始路由标签或凭据。

系统通知分别报告上下文降级和官方额度耗尽。降级按线程／模型去重，无稳定ID的独立尝试不共用全局匿名提醒；官方按账号锁存，明确恢复后再次耗尽可提醒。队列只含固定说明和来源名称、最多100条，通知后确认移除。首次由macOS请求通知权限；拒绝时应用内聚合同批消息，不只显示最后一条。
