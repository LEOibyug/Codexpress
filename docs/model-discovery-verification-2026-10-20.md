# 模型发现与本地代理端口验收

新增来源默认自动获取模型，支持切换为手动填写。源卡片显示缓存数量、刷新入口及失败状态。表单只需填写本地代理端口，正常新输入使用本机 HTTP 代理；已有本地 SOCKS 协议及未修改的远程代理继续兼容。

## 自动检查

- `bash scripts/check.sh`：39 项 Rust 测试通过，Clippy 在 `-D warnings` 下通过，Swift 构建通过。
- `swift test`：12 项测试通过，新增端口规范化、旧代理兼容及手动列表迁移检查。
- `bash scripts/build.sh`：arm64 release 应用打包及 ad-hoc 签名校验通过。
- 将大小写 HTTP_PROXY／HTTPS_PROXY／ALL_PROXY 全部设为失效的本地端口、清空 NO_PROXY 后，4 项模型发现集成测试仍通过。

模型测试仅访问 localhost，检查草稿查询不改变运行来源、不写入生成用量，API 路径与 Bearer 头，排序去重，代理故障不回退，禁止重定向，超大／空／错误响应的安全失败。官方模型请求检查固定目录 URL、已保存来源身份及模拟代理 CONNECT，不访问真实官方账号。

## 原生界面与状态检查

使用单独的测试应用标识、临时状态目录和本机模拟供应商。填入测试地址和虚拟密钥后，未保存即自动显示 3 个模型。选择指定代理并仅输入本地端口后查询成功；保存后核对缓存 ID、自动模式及规范化代理 URL，元数据不含虚拟密钥。

把端口改为不可用端口后，表单显示查询失败且保留 3 个模型；把模拟供应商改为 HTTP 401 后，源卡片显示错误，旧模型数量保持不变。未执行真实 OAuth、生成、重置卡消费或 Codex 配置接管。真实官方模型目录仍需账号验收。
